# Skate Performance Dashboard V2

Dashboard Streamlit para CSVs exportados do Sportscode.

## V2
- Upload independente da foto do atleta
- Nome do atleta editável
- Upload de múltiplos CSVs
- Cada CSV é mantido como uma sessão/treino
- Filtro por sessão ou visão consolidada
- Evolução da taxa de acerto entre treinos
- KPIs, donuts e tabela de manobras

Main file: `app.py`

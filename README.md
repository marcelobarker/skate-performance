
# Skate Performance Dashboard

Protótipo Streamlit para ler CSVs exportados do Sportscode e gerar o dashboard automaticamente.

## Como testar no seu PC

1. Instale Python 3.11 ou superior.
2. Abra o Prompt de Comando dentro desta pasta.
3. Rode:

```bash
pip install -r requirements.txt
streamlit run app.py
```

O navegador abrirá o dashboard. Arraste o CSV do Sportscode para a área de upload.

## Como colocar online depois

Crie um repositório no GitHub com `app.py` e `requirements.txt`, conecte esse repositório ao Streamlit Community Cloud e selecione `app.py` como arquivo principal.
